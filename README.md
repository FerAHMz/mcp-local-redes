# Servidor MCP local para telemetría de flota

Proyecto 1 del curso CC3067 Redes, sección 10, Universidad del Valle de Guatemala.

Servidor MCP (Model Context Protocol) implementado desde cero sobre `stdio`, sin SDK
ni librerías de protocolo, que expone consultas de telemetría vehicular como
herramientas invocables por un modelo de lenguaje.

Las instrucciones de instalación y uso las voy agregando conforme avance el proyecto.
